# NextLine 下载

NextLine 是一个悬在会议窗口上面的小窗口：实时双语字幕让你听懂，一张提示卡告诉你下一句说什么。有 Mac 版和 Windows 试用版。

介绍页：https://nextline-landing.vercel.app

## 下载

到 [Releases](https://github.com/F1reC/nextline-releases/releases/latest) 下载：Mac 是 `.dmg`，Windows 是 `.zip`。

翻译和提示调用 DeepSeek 的接口，密钥是你自己的，填在设置里。

## Mac

需要 macOS 26 或更新的系统、Apple 芯片。

这是早期版本，安装包还没有 Apple 的开发者签名：

1. 打开 `.dmg`，把 NextLine 拖进“应用程序”
2. 打开 NextLine，系统会提示无法验证，先点“完成”
3. 到 系统设置 › 隐私与安全性，往下找到 NextLine，点“仍要打开”

## Windows（试用版）

需要 64 位的 Windows 10 或 11。这个版本还没有充分测试，可能遇到打不开或出错的情况。

1. 解压 `.zip`
2. 运行文件夹里的 `NextLine.exe`，不用安装
3. Windows 提示“未知发布者”时，点“更多信息”，再点“仍要运行”

这个仓库只放安装包。
